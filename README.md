# Smart LMS — Платформа для онлайн-обучения
Платформа для онлайн-обучения с геймификацией, адаптивным треком и ИИ-аудитом ссылок.


## О проекте
Веб-приложение для онлайн-обучения с отслеживанием прогресса. 

## Функциональность
- Список доступных курсов
- Страница курса с уроками
- Страница урока с контентом
- Отметка урока "Пройдено"
- Сохранение прогресса (localStorage)
- Личный кабинет с прогрессом по курсам

## Технологии
- HTML5
- CSS3
- JavaScript
- LocalStorage для хранения данных

## Страницы
- Главная — список курсов
- Курс — уроки внутри курса
- Урок — содержание урока и кнопка "Пройдено"
- Профиль — прогресс по всем курсам
